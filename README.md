# Shopping List Application

## Project 6

A simple web application for preparing and managing a shopping list.

## Features

- Add shopping items
- Specify quantity
- Mark items as purchased
- Edit shopping items
- Delete shopping items
- Search shopping items
- Store data using browser Local Storage
- Display total number of items
- Validate empty and invalid input

## Technologies

- HTML
- CSS
- JavaScript
- Local Storage

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html` in a web browser.
3. Add items and quantities using the form.
4. Use the Purchased, Edit, Delete, and Search features to manage the list.

## Project Files

- `index.html` — application structure
- `style.css` — application design
- `script.js` — application functionality
